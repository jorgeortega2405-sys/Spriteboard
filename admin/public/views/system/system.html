Sistema

Seguridad y Políticas de Contraseñas

Reglas de complejidad para credenciales de acceso, duración de sesiones y concurrencia.

Longitud mínima de contraseña

Número mínimo de caracteres exigidos al crear o restablecer contraseñas (mín. 4, máx. 64).

Longitud máxima de contraseña

Límite superior de caracteres permitidos para contraseñas de usuarios (mín. 16, máx. 256).

Duración de sesiones (en días)

Tiempo de validez de sesiones activas antes de requerir nuevo inicio de sesión (mín. 1, máx. 90).

Máximo de cuentas simultáneas

Número máximo de cuentas que un usuario puede mantener vinculadas a la vez (mín. 1, máx. 20).

Requerir letra mayúscula

Exige al menos una letra mayúscula (A-Z) en la contraseña.

Requerir letra minúscula

Exige al menos una letra minúscula (a-z) en la contraseña.

Requerir números

Exige al menos un número (0-9) en la contraseña.

Requerir carácter especial

Exige al menos un carácter especial (@, #, $, %, etc.) en la contraseña.

Usuarios, Registro y Dominios

Control de creación de cuentas, inicio con proveedores externos y dominios de correo permitidos.

Longitud mínima de nombre de usuario

Número mínimo de caracteres para nombres de usuario (mín. 1, máx. 20).

Longitud máxima de nombre de usuario

Número máximo de caracteres para nombres de usuario (mín. 10, máx. 100).

Habilitar registro de nuevos usuarios

Permite a nuevas personas crear cuentas en la plataforma.

Autenticación con Google (OAuth 2.0)

Habilita o pausa el inicio de sesión y vinculación con Google.

Restringir registro por dominio de correo

Si está activado, únicamente se permitirá el registro con los dominios autorizados.

Dominios de correo permitidos

Ingresa los dominios sin arroba (@), separados por comas (ej. gmail.com, outlook.com).

Verificación y Tiempos de Espera (Cooldowns)

Límites de frecuencia para cambio de identificadores, caducidad de tokens y códigos OTP.

Espera para cambio de usuario (días)

Días que debe esperar un usuario antes de volver a modificar su nombre de usuario (mín. 0, máx. 365).

Espera para cambio de correo (días)

Días que debe esperar un usuario antes de volver a actualizar su correo (mín. 0, máx. 365).

Validez de código de verificación (minutos)

Minutos de vida útil para códigos OTP de verificación enviados por email (mín. 1, máx. 120).

Intentos máximos antes de invalidar código

Intentos fallidos tolerados antes de invalidar un código OTP activo (mín. 1, máx. 20).

Validez de enlace de reseteo (minutos)

Minutos de vigencia para el enlace de restablecimiento de contraseña (mín. 1, máx. 120).

Ventana de autorización sensible (minutos)

Tiempo concedido tras validar contraseña antes de volver a solicitarla (mín. 1, máx. 60).

Almacenamiento y Archivos Multimedia

Límites de tamaño para fotos de perfil, avatares y tipos MIME permitidos.

Tamaño máximo de avatar (MB)

Peso máximo permitido en megabytes para fotos de perfil de usuarios (mín. 1, máx. 25).

Formatos MIME permitidos

Tipos MIME aceptados para subida de fotos de perfil (separados por coma).

Mantenimiento y Datos de la Plataforma

Estado de mantenimiento global, nombres corporativos y correo de soporte.

Activar Modo Mantenimiento

Muestra pantalla de mantenimiento a usuarios y bloquea operaciones no administrativas.

Mensaje durante mantenimiento

Texto informativo mostrado a los usuarios cuando el sitio se encuentra en mantenimiento.

Nombre de la aplicación

Nombre público utilizado en correos, notificaciones y títulos de página.

Correo de soporte técnico

Dirección de contacto mostrada a los usuarios para asistencia.

Límites de Peticiones y Protección Anti-Abuso

Parámetros de protección contra ataques de fuerza bruta y saturación de IA.

Límite de intentos de inicio de sesión

Máximo de intentos de login permitidos cada 5 minutos por IP (mín. 1, máx. 100).

Límite de solicitudes de registro

Máximo de intentos de registro permitidos cada 15 minutos por IP (mín. 1, máx. 100).

Límite de mensajes al asistente IA

Máximo de mensajes por minuto permitidos por usuario en el chat de IA (mín. 1, máx. 200).
